

# Components
Hypotheses: Null and Alternative
Null Hypothesis: Baseline or No-change.
    The claim that is assumed to be true.
    Denoted: H0
Alternative Hypothesis: 
    Conjecture you are testing for.
    Against the Null Hypothesis.
    Denoted: HA
Sample Data
Statistic:
    Calculated according to the parameters detailed in the hypotheses.
